# DataViewer

여러 개의 CSV/Excel 파일을 하나로 결합하고 그래프로 한눈에 보는 Windows 데스크톱 프로그램입니다.

## 기능
- CSV(.csv), Excel(.xlsx/.xls) 파일을 드래그 앤 드롭 또는 파일 선택 버튼으로 불러오기
- 같은 열 구조를 가진 여러 파일을 행 단위로 결합
- 결합된 데이터를 표로 확인
- X축/Y축을 선택해 선 그래프로 시각화 (Y축은 여러 개 선택 가능)

## 설치
```bash
pip install -r requirements.txt
```

## 실행
```bash
python main.py
```

## 사용법
1. "파일 열기" 버튼이나 드래그 앤 드롭으로 CSV/Excel 파일을 추가합니다.
2. "결합하기" 버튼을 눌러 파일들을 하나의 표로 합칩니다. (열 구조가 같은 파일만 결합됩니다)
3. X축과 Y축(복수 선택 가능) 컬럼을 선택하고 "그래프 그리기"를 누릅니다.
